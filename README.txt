Vishwakarma Furniture - app

GitHub Pages par chalane ke steps:
1. github.com par naya repository banao (jaise: vishwakarma).
2. Is zip ke andar ki sari files (index.html, manifest.json, sw.js, jspdf.min.js, icons folder) repository me upload karo.
3. Settings > Pages > Branch: main, folder: / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/vishwakarma/

APK banane ke liye:
1. pwabuilder.com kholo, upar apna GitHub Pages link daalo.
2. Package for stores > Android > Generate. APK download karo.

Note: data usi phone/browser me save hota hai. Browser data clear karoge to data ud jayega.
